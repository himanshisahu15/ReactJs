# 🔢 React Counter App using React Redux

This is a basic counter application built with **React** and **React Redux** (without Redux Toolkit). It demonstrates the fundamental concepts of Redux such as **store**, **reducer**, **actions**, and **connectivity via `useSelector` and `useDispatch`**.

---

## 🚀 Features

- ➕ Increment counter
- ➖ Decrement counter (with no negative values)
- 🔄 Reset counter
- 🧠 Uses classic Redux setup (store, reducer, actions)
- 🧩 Connected to React via `react-redux`
- 🎯 Very useful for understanding Redux fundamentals

---

## 🏗️ Tech Stack

- ⚛️ React
- ⚙️ Redux
- 🧰 React Redux
- 🎨 CSS Modules (optional)

---


## 🧠 Redux Concepts Used

- **Store** (`createStore`)
- **Actions** (`INCREMENT`, `DECREMENT`, `RESET`)
- **Reducer** (`counterReducer`)
- **React Integration** via `Provider`, `useSelector`, `useDispatch`
